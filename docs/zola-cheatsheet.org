#+title: Zola Cheatsheet

* 隱藏／刪除文章
| 目的       | 在 org 裡怎麼做                                | 之後要做的                        |
|------------+------------------------------------------------+-----------------------------------|
| 暫時隱藏   | 標題改成 =* TODO 標題=（改回或改 DONE 就公開）  | 存檔即可（md 會帶 =draft = true=） |
| 暫時隱藏   | =:PROPERTIES:= 加 =:EXPORT_HUGO_DRAFT: true=    | 存檔即可                          |
| 不匯出     | 標題加 tag =:noexport:=                         | =./scripts/org2md.sh --clean=     |
| 刪除       | 刪掉該 subtree 或整個 org 檔                    | =./scripts/org2md.sh --clean=     |

- 預覽草稿：=zola serve --drafts=

* org2md.sh
- =./scripts/org2md.sh=：append，匯出／覆蓋 md，不刪檔
- =./scripts/org2md.sh --clean=：刪掉 =content/= 裡匯出的 md（保留 =_index.md=）後全部重產

* 標題 tag
- 寫在標題最後：=* 標題 :@blogging:emacs:=
- =@= 開頭 → categories；沒有 =@= → tags
- 上例匯出成 =categories = ["blogging"]=、=tags = ["emacs"]=

* PROPERTIES 可用的 key
| key                    | 例            | 匯出成                       |
|------------------------+---------------+------------------------------|
| EXPORT_FILE_NAME       | hello-zola    | md 檔名（必填）              |
| EXPORT_DATE            | 2026-10-07    | date                         |
| EXPORT_HUGO_LASTMOD    | 2026-10-08    | updated                      |
| EXPORT_HUGO_SLUG       | my-slug       | slug（網址）                 |
| EXPORT_HUGO_DRAFT      | true          | draft                        |
| EXPORT_TITLE           | 另一個標題    | title（預設用標題文字）      |
| EXPORT_DESCRIPTION     | 一句摘要      | description                  |
| EXPORT_AUTHOR          | Someone       | author                       |
| EXPORT_HUGO_WEIGHT     | 10            | weight（排序）               |
| EXPORT_HUGO_ALIASES    | /old/a /old/b | aliases（舊網址轉址）        |
| EXPORT_HUGO_TAGS       | a b           | tags（會蓋掉標題上的 tag）   |
| EXPORT_HUGO_CATEGORIES | x             | categories（會蓋掉 @ tag）   |
| EXPORT_HUGO_LAYOUT     | custom.html   | template（指定模板）         |

* 中文檔名
- =EXPORT_FILE_NAME= 可用中文：md 檔名是中文，網址會轉成拼音（=/posts/zhong-wen-dang-ming/=）
- 自己決定網址：加 =EXPORT_HUGO_SLUG=（=EXPORT_ZOLA_SLUG= 沒作用）

* 一篇一個 org 檔：檔案開頭的 keyword
| keyword           | 例              | 匯出成                                |
|-------------------+-----------------+---------------------------------------|
| #+title           | 文章標題        | title                                 |
| #+date            | 2026-10-07      | date                                  |
| #+hugo_slug       | my-slug         | slug（網址；留空會讓 zola build 失敗） |
| #+hugo_lastmod    | 2026-10-08      | updated                               |
| #+hugo_draft      | true            | draft                                 |
| #+description     | 一句摘要        | description                           |
| #+author          | Someone         | author                                |
| #+hugo_weight     | 10              | weight（排序）                        |
| #+hugo_aliases    | /old/a /old/b   | aliases（舊網址轉址）                 |
| #+filetags        | @blogging emacs | =@= 開頭 → categories，其餘 → tags    |
| #+hugo_tags       | a b             | tags（會蓋掉 filetags）               |
| #+hugo_categories | x               | categories（會蓋掉 =@= filetags）     |

- md 檔名 = org 檔名；不用寫 =#+hugo_section=，預設進 =posts/=

* 內文語法 → 網頁
| org                                   | md                         | 網頁 HTML                  |
|---------------------------------------+----------------------------+----------------------------|
| =*粗體*=                              | =**粗體**=                 | =<strong>=                 |
| =/斜體/=                              | =_斜體_=                   | =<em>=                     |
| =_底線_=                              | =<span class="underline">= | =<span class="underline">= |
| =+刪除線+=                            | =~~刪除線~~=               | =<del>=                    |
| ~=verbatim=~ ／ =~code~=              | =`code`=                   | =<code>=                   |
| =H_{2}O= ／ =x^{2}=                   | =<sub>= ／ =<sup>=         | =<sub>= ／ =<sup>=         |
| =** 二級標題=                         | =## 二級標題=              | =<h2 id="二級標題">=       |
| =- 項目=                              | =- 項目=                   | =<ul><li>=                 |
| =1. 項目=                             | =1. 項目=                  | =<ol><li>=                 |
| =- [ ] 待辦= ／ =- [X] 完成=          | =- [ ]= ／ =- [X]=         | =<input type="checkbox">=  |
| =[[https://a.com][文字]]=             | =[文字](https://a.com)=    | =<a rel="external">=       |
| =#+begin_src python=                  | =```python=                | =<pre><code>=（有高亮）    |
| =: 一行= ／ =#+begin_example=         | =```text=                  | =<pre><code>=              |
| =#+begin_quote=                       | => 引用=                   | =<blockquote>=             |
| =#+begin_details= + =#+begin_summary= | =<details>=                | 可點開的摺疊區塊           |
| org 表格                              | md 表格                    | =<table>=                  |
| =註[fn:1]= + 文末 =[fn:1] 內容=       | =[^fn:1]=                  | 上標數字＋文末註腳         |
| =-----=                               | =---=                      | =<hr>=                     |

- 段落：空一行才分段
- 不能用：=名詞 :: 解釋=（網頁顯示成純文字）、=$數學$=（沒裝 KaTeX）、圖片（目前會讓 zola build 失敗）

* 提示框
#+begin_quote
[!NOTE]
內容
#+end_quote

- 種類：=NOTE= =TIP= =IMPORTANT= =WARNING= =CAUTION=
- 網頁 HTML：=<blockquote class="markdown-alert-note">=
